Using a different SIS? ▸ CSV format requirements

Two formats are accepted. Use whichever your SIS supports:

Option 1 — Name column (preferred)

Include a Name column where each value is LastName, FirstName. Extra columns are ignored.

"Name","StudentID"
"Hardy, Grayer","12345"
"Wong, Eric","12346"

→ displays as Grayer H, Eric W

Option 2 — Separate FirstName & LastName columns

Include both FirstName and LastName columns. Extra columns are ignored.

"FirstName","LastName","StudentID"
"Grayer","Hardy","12345"
"Eric","Wong","12346"

→ displays as Grayer H, Eric W

Column headers are case-insensitive. Values may be quoted or unquoted.
